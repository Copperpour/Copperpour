AI-assisted PCB design
for KiCad 10

Copperpour is an open-source KiCad plugin and MCP server. It lets Claude and other AI assistants work on your schematics and boards directly: placing and wiring parts, laying out the PCB, running checks and exporting production files.

What it does

Instead of describing changes and applying them by hand, your assistant works on the KiCad project itself, through the Model Context Protocol.

Schematic capture

Place symbols from KiCad's libraries and wire them by pin name, with revision-checked writes that stop rather than overwrite a newer save.

PCB layout

Place, move and route footprints live through KiCad 10's IPC API, with KiCad's own undo and redo.

Design checks

ERC, DRC, connectivity, decoupling and power-rail audits, and BOM health checks.

Production files

Gerbers, drill files, BOM, pick-and-place, 3D models and PDF from kicad-cli.

Parts and templates

Search a local JLCPCB catalog for in-stock parts, and start from reference circuits like USB-C, LDO, buck and I²C.

One small binary

A single Rust executable, with no Node.js or Python to install. Toolsets load on demand to keep the assistant's context small.

Install

You need KiCad 10 on Windows, macOS or Linux, and an MCP client such as Claude Desktop, Claude Code or Codex.

Your system
Your AI client

  1. Install the Claude Desktop extension (Claude Desktop)

    Download the extension for your system from the latest release:

    Windows: copperpour-v<version>-windows-x86_64.mcpb

    macOS: copperpour-v<version>-macos-universal.mcpb, a universal build for Apple Silicon and Intel Macs.

    Linux: copperpour-v<version>-linux-x86_64.mcpb. Claude Desktop for Linux is a beta or community build; see the Linux notes.

    In Claude Desktop, open Settings → Extensions → Advanced settings → Install Extension… and choose the file, or double-click it. There are no configuration files to edit.

    The extension carries its own Copperpour server, so you don't need the KiCad plugin. Install it as well only for Copperpour's KiCad toolbar action and settings dialog, or the native Specctra export bridge. See the Claude Desktop extension guide.

  2. Turn on the KiCad API (Claude Desktop)

    In KiCad 10, turn on Preferences → Plugins → Enable KiCad API. The PCB tools need KiCad running with the board open. Schematic editing, exports, ERC and DRC work without the KiCad window.

  3. Install the plugin into KiCad (other clients)

    Download the KiCad package for your system from the latest release:

    Windows: copperpour-pcm-v<version>-windows.zip

    macOS: copperpour-pcm-v<version>-macos.zip, a universal build for Apple Silicon and Intel Macs.

    Linux: copperpour-pcm-v<version>-linux.zip, for x86_64.

    copperpour-pcm-v<version>.zip, without an OS in its name, carries all three systems.

    In KiCad, open Plugin and Content Manager → Install from File, choose the zip and restart KiCad. Then turn on Preferences → Plugins → Enable KiCad API, which the PCB tools need.

  4. Connect your AI client (other clients)

    Claude Code

    Add the server to .mcp.json in your project's root:

    {
  "mcpServers": {
    "copperpour": { "command": "/path/to/copperpour" }
  }
}

    Codex

    codex mcp add copperpour -- "/path/to/copperpour" --client codex

    Other MCP clients

    Register a stdio server whose command is the Copperpour binary, with no arguments. Most clients take this shape:

    {
  "mcpServers": {
    "copperpour": { "command": "/path/to/copperpour" }
  }
}

    The KiCad package installs the server at C:\Users\<YOU>\Documents\KiCad\10.0\3rdparty\plugins\com_github_copperpour_copperpour\bin\copperpour.exe on Windows; replace <YOU> with your user name, ~/Documents/KiCad/10.0/3rdparty/plugins/com_github_copperpour_copperpour/bin/copperpour on macOS, ~/.local/share/kicad/10.0/3rdparty/plugins/com_github_copperpour_copperpour/bin/copperpour on Linux. If your client doesn't expand ~, write out your home folder instead.

  5. Check that it works

    Ask your assistant something read-only about an existing project:

    Show the project info for ~/kicad/myboard/myboard.kicad_pro.

    It should answer with the project's name, its schematic and PCB paths, and the KiCad version that wrote them. If the tools don't show up, ask for get_installation_info, or see Troubleshooting.

Standalone server binaries, optional skills for Claude Code, Codex, Gemini CLI and Cursor, and other setups are in the full installation guide. Coming from Konnect? Read Migrating from Konnect first.
