### `create_footprint` supports silkscreen modes and side-specific courtyards (minor release)

Set `silkscreen` to `outline` (the default) for the generated front silk outline
and pin-1 dot, `pin1_only` for the dot alone, or `none` for neither. The
Reference stays on `F.SilkS`, and the fab chamfer is still generated. The
`pin1_marked` result reports whether a silk dot was written. It is false when
the mode suppresses the dot or no tested position fits inside the outline
with clearance from the pad extents.

Front copper gets an `F.CrtYd` and back copper gets a `B.CrtYd`. Through-hole
pads and pads on both copper sides get both. Footprints with only technical
pad layers retain the front courtyard. Each generated courtyard encloses the
pad envelope and the supplied body when present.

Footprints generated by `import_jlcpcb_part` use the same courtyard and
pin-1 placement rules with the default silkscreen mode.
