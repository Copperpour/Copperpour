## How to Merge Upstream PRs While Preserving Original Authorship

All 60 open PR branches are fetched into your local git repository under `upstream-prs/<NUMBER>`. Because git commits store the original `Author:` metadata inside the commit object, merging or cherry-picking from `upstream-prs/<NUMBER>` **automatically preserves the original contributor's name and email**.

```bash
# 1. Inspect the PR commits, author, and diff against main:
git log --format=fuller main..upstream-prs/<PR_NUMBER>
git diff main...upstream-prs/<PR_NUMBER>

# 2a. Merge cleanly (preserves original commit(s) and author):
git merge --no-ff upstream-prs/<PR_NUMBER> -m "Merge upstream PR #<PR_NUMBER> by @<handle>"

# 2b. Or cherry-pick / rebase (also preserves original author automatically):
git cherry-pick main..upstream-prs/<PR_NUMBER>

# 2c. If squashing multiple commits, explicitly keep the original author:
# git merge --squash upstream-prs/<PR_NUMBER>
# git commit --author="Author Name <email>" -m "..."
```
